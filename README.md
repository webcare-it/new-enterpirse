# Webacare Laravel Boilerplate

A professional Laravel backend boilerplate developed by **Webacare**, designed for rapid application development using **Laravel** and **Bootstrap**.

---

## Features

- Laravel latest version support
- Clean MVC architecture
- Bootstrap-based admin panel
- Authentication system (Login, Register, Logout)
- Role & Permission ready (extendable)
- CRUD boilerplate structure
- Reusable components
- RESTful API ready
- Secure and scalable code structure

---

## Tech Stack

- **Backend:** Laravel
- **Frontend (Admin Panel):** Bootstrap 5
- **Database:** MySQL
- **Authentication:** Laravel Auth / Breeze / Custom
- **Server:** Apache / Nginx

# Webacare Laravel Boilerplate - Installation Guide

This guide will help you set up the **Webacare Laravel Boilerplate** (Laravel + Bootstrap backend) on your local machine.

---

## Requirements

Make sure your system meets the following requirements:

- PHP >= 8.2
- Composer
- Node.js & npm
- MySQL / MariaDB
- Apache / Nginx (or Laravel built-in server)
